# Contributing

- One fix per PR, titled `[alert <fingerprint>] <short description>`.
- Every bug-fix PR adds a regression test that reproduces the alert's failing input.
- `services/payments/` belongs to the Payments team (PCI scope). Platform and
  automation never open PRs there. Open an issue labelled `payments` instead.
- This repo is public. Never paste customer data (emails, names, addresses)
  into issues, PRs, commits or tests. Use made-up values.
- A human on Platform approves and merges every PR.
